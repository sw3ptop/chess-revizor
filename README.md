# Ревизор партий

Бесплатный разбор шахматных партий в браузере, в духе Game Review на chess.com.

- Stockfish работает прямо в браузере, сервер не нужен
- Оценка каждого хода: блестяще, сильный, лучший, отлично, хорошо, неточность, ошибка, упущение, зевок
- Лучший ход со стрелкой на доске и вариантом движка
- Точность игроков, график оценки, шкала преимущества

## Как пользоваться

Открой сайт: https://sw3ptop.github.io/chess-revizor/

- **PGN**: на chess.com открой партию → Поделиться → PGN → Копировать, вставь и нажми «Разобрать».
- **Ссылка или ник**: введи ник любого из игроков (и, если есть, ссылку на партию), и страница сама подтянет её через публичный API chess.com.

Разбирай только завершённые партии.
